# Employee Dashboard — Employees Currently in Kitchen

- Added an `Employees Currently in Kitchen` card directly below `Recent Activities` on the employee dashboard.
- The card follows the Recent Activities visual style and displays employee profile photos (or initials when no photo is uploaded), name, branch, live status, and check-in time.
- The dashboard snapshot now includes active check-ins for the signed-in employee's assigned branch. Admin / all-scope users receive the full active list; regular employees only receive colleagues assigned to the same branch.
- The existing admin workforce panel remains available.
