# Enhancements
- English UI notifications use on-screen pop-up toast messages.
- Bell opens notifications only; request approval changes are persisted to Neon.
- Punch button reflects open session, shows location verification spinner, and is disabled during checks.
- Employees can edit name, photo (max 140 KB), password. Admin can reset password.
- Requests now have type, start/end dates, and explanation.
- Off-canvas sidebar closes when clicking backdrop.
- Installable PWA manifest and minimal service worker, requires HTTPS.
- Existing Neon records are retained; schema uses additive changes.
- Server-side geofence enforcement unchanged.
- Not yet audited for production security / full mobile offline support.
