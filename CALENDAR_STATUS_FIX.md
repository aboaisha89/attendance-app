# Calendar status dot update

Each day displays its own status dot in the calendar: green = completed required hours, orange = checked out short of required hours, blue = completed overtime, red = absence, purple = admin leave. Gray = attendance with no measurable required-hours classification or still-open session. No dot before account creation.

Time totals subtract recorded breaks. All sessions grouped under original check-in date, including overnight sessions. Click a date to select only that date and show its events in Attendance History.

If required-hours snapshot exists it takes precedence; otherwise the user-level requirement is used. Important: absent day classification is only reliable where the employee's workdays are configured; do not treat weekly rest days as absences for payroll without explicit schedule logic.
